================================================================
  UTAU_VChat  1.0.0  ·  首次使用必读
================================================================

【怎么启动】
  安装程序装的：开始菜单 → UTAU_VChat
  绿色版：      进入解压出的 UTAU_VChat 文件夹，双击 UTAU_VChat.exe

【第一次运行会做什么】
  1) 弹出设置窗口，要求填写你自己的 DeepSeek API Key
     —— 本软件不包含任何密钥，必须填你自己的
     —— 获取地址：https://platform.deepseek.com/api_keys
     —— 另外两栏（API 地址 / 模型名）保持默认即可
  2) 填好后选择运行模式：
     ・GUI 界面（歌姬立绘背景，窗口可缩放）
     ・CLI 命令行（终端风格，启动快）
  3) 在输入框打字、回车，角色就会用 UTAU 声库念出来

【日常怎么用】
  ・直接打字 = 聊天。回复会显示出来并自动播放语音。
  ・输入 /set 打开设置面板，会列出全部可调项、当前值和修改语法。
  ・改完立即保存，而且各角色独立（给 Teto 调的不影响 Adachi）。
  ・生成的音频放在程序目录的 out\ 里，文件名如 reply_<时间戳>.wav

【常用命令（界面提示行里就这几条）】
  /voice teto|adachi 角色      切换角色：teto / adachi
  /lang ja|zh 说话语言         说话语言（配音用哪种语言）
  /dlang zh|ja|auto 显示语言    显示语言（可与说话语言不同）
  /set 设置                    打开设置面板（全部调参都在这里）
  /help 帮助                   重新打印提示行
  q 退出

  写法就是「命令 + 可选值」，照着提示行抄即可；后面是中文说明。

【觉得不好听就调这几个】（改法都是 /set <项目> <值>）
  /set speed 1.3   说话太慢、字黏在一起 → 调大（更慢、字间隔更开）
  /set pitch 2.5   语调太平 → 调大（放大音高起伏）
  /set tone 60     整体音太高/太低 → 调整基准音高（40~80）
  /set pause 2.0   句子之间太赶 → 调大
  /set emo off     不想让它情绪化演绎 → 关掉
  /set lang zh     想听中文发音（施工中，效果与最终版有差异）
  /set dlang zh    说日语但想看懂文字 → 显示中文

  不确定某项的范围？只打项目名即可，例如 /set speed 会显示
  「语速: ×1.15　（/set speed 0.5 ~ 3.0）」

【已内置的组件（无需另装任何东西）】
  ・OpenUtau 合成引擎（仅功能部分，不含 GUI）
  ・Worldline 声码器
  ・VOICEVOX CORE 语调引擎 + 四国めたん语音模型
  ・Open JTalk 日语词典
  ・UTAU 声库：重音テト / 足立レイ
  ・Python 运行时与全部依赖

【安装位置】
  安装程序默认装到：  C:\Program Files\UTAU_VChat
  在「选择目标位置」页点「浏览」可以改成任意目录。
  没有管理员权限就用命令行加 /CURRENTUSER，装到用户目录、不弹 UAC。

  C:\Program Files 默认不可写，所以配置和输出会自动改存到：
      %LOCALAPPDATA%\UTAU_VChat\
  即：程序/引擎/声库在 Program Files（只读），
      config.json、characters.json、out\ 在用户目录。
  想全部放在一起（完全便携），就装到 D:\UTAU_VChat 这类可写目录。
  用 UTAU_VChat.exe --diag 可以看到实际使用的数据目录。

  绿色版请解压到【有写入权限】的目录：
      桌面、文档、D:\UTAU_VChat
  （放进 Program Files 也能用，同样会自动回退到用户目录。）

【出问题了先自检】
  开始菜单里有「自检」快捷方式；也可以打开命令行(cmd)，
  cd 到本目录，然后运行：
      UTAU_VChat.exe --selftest     检查渲染器/语音引擎/声库是否齐备
      UTAU_VChat.exe --diag         查看路径解析与编码环境
  自检会实际合成两句话（两个声库各一句），全部显示 OK 即表示可用。

【常见报错】
  HTTP 401              API Key 填错或已失效，重开程序重新填
  HTTP 402 / Insufficient Balance   DeepSeek 账户余额不足
  没有声音               检查系统默认播放设备；音频在 out\ 里可手动播放
  「没有可朗读的内容」    回复全是括号或符号，被朗读过滤器剥掉了

【卸载】
  安装程序装的：开始菜单 →「卸载 UTAU_VChat」
  绿色版：      直接删掉 UTAU_VChat 文件夹
                （若曾回退，连 %LOCALAPPDATA%\UTAU_VChat 一起删）

  安装程序卸载时会清掉全部内容，不留残留：
    ・整个程序目录（含引擎、声库、渲染缓存）
    ・%LOCALAPPDATA%\UTAU_VChat（配置、角色设置、生成的音频）
    ・%TEMP%\utauchat_*.ico（运行时生成的图标缓存）
    ・注册表项、开始菜单与桌面快捷方式

  ⚠ 卸载会把 config.json 里的 API Key 一起删掉。
    想保留就先备份 %LOCALAPPDATA%\UTAU_VChat\config.json。
  ⚠ 若装在自定义目录，卸载会删除该目录，里面别放别的东西。

【全部设置项一览】（都通过 /set 修改）
  /set voice teto|adachi        角色
  /set lang ja|zh               说话语言
  /set dlang zh|ja|auto         显示语言（可与说话语言不同）
  /set tone 40~80               基准音高
  /set pitch 0.5~4.0            音域夸张度
  /set speed 0.5~3.0            吐字速度（>1 更慢、字与字间隔更大）
  /set pause 0.2~4.0            句间停顿
  /set emo on|off               情绪语气开关
  /set breath -100~100          气声量
  /set tension -100~100         紧张度
  /set velocity 0~150           辅音速度
  /set learn <音频路径>          分析参考音频并自动调参
  /set                          打开设置面板（列出全部当前值）
  /set <项目>                   只看该项当前值与范围

  上面除 /set 之外的写法都只是快捷方式，等价于 /set 的对应项。
